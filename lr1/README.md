# ЛР1. Система бронювання квитків на автобус

## Опис

Консольний застосунок для бронювання квитків на автобус.

Основна сутність — квиток.

Програма отримує від користувача:

- номер квитка;
- ціну квитка;
- кількість місць;
- місто відправлення;
- місто прибуття.

Після введення даних програма розраховує загальну вартість квитків.
